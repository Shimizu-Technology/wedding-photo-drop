# Wedding Photo Drop

A Rails + React monorepo for collecting guest photos/videos at weddings and events.

## Structure

- `api/` — Rails 8 API-only backend
- `web/` — React + Vite + TypeScript frontend

## MVP

Guests use a private upload link/QR code to submit photos or videos. Admins review all uploads, approve selected media, and the public gallery shows approved media only.
